# URL Shortening Service

Project made to complete URL Shortening Service challenge in roadmap.sh

Link to the challenge: https://roadmap.sh/projects/url-shortening-service

# Instructions

- Set environment variables to start the server and connect to the MongoDB cluster;
- run "npm start"
- Backend ready to serve shortening URL API
